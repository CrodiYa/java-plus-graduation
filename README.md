# Explore With Me

Приложение для размещения и поиска событий, построенное на микросервисной архитектуре.

## Микросервисы

| Сервис | Назначение |
|--------|------------|
| **event-service** | События, категории, подборки событий |
| **user-service** | Пользователи |
| **request-service** | Запросы на участие в событиях |
| **comment-service** | Комментарии к событиям |
| **stats-service** | Сбор статистики просмотров событий |

## Инфраструктура

- **Discovery Server** (Eureka) — обнаружение и регистрация сервисов
- **Config Server** — централизованное хранение конфигураций
- **Gateway Server** — единая точка входа, маршрутизация запросов

## Общие модули

- **interaction-api** — общие DTO и Feign-клиенты для взаимодействия между сервисами

## Взаимодействие

Сервисы общаются между собой синхронно через **Feign Client**. Клиенты и DTO вынесены в общий модуль `interaction-api`.
